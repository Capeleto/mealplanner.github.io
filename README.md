# 🍽️ Meal Planner — Planejador Semanal de Refeições

### [The Meal Planner](mealplanner.github.io)

Next.js 14 (App Router, static export) · TypeScript · Tailwind CSS · i18n PT/EN · light/dark theme · GitHub Pages deploy.

## ✨ Features
- 📋 Planejador semanal completo (9 seções)
- 🌐 i18n PT/EN com dicionários separados
- 🌗 Tema claro/escuro (persistido + respeita o SO)
- 💾 Salvamento automático no `localStorage`
- 🖨️ Imprimir / salvar como PDF
- 🚀 Deploy automático no GitHub Pages

## 🚀 Rodando localmente
```bash
npm install
npm run dev          # http://localhost:3000
```

## 🏗️ Build
```bash
npm run build        # gera ./out (export estático)
```
